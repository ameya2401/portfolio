# Ameya Bhagat — Portfolio

Personal portfolio and engineering showcase built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Cloudflare Kumo UI.

🔗 **Live:** [portfolio-ameya.vercel.app](https://portfolio-ameya.vercel.app/) (or your deployment URL)  
👤 **Portfolio of:** [Ameya Bhagat](https://github.com/ameya2401)  
📫 **Contact:** ameyabhagatwork@gmail.com

---

## ✨ Features

- **Modern Architecture**: Next.js 14 App Router with React 18 and TypeScript.
- **Dynamic Interactions**: Framer Motion transitions, interactive Spotify vinyl player, and live GitHub contribution graph with an interactive Snake game.
- **Engineering Philosophy & Systems Thinking**: Interactive multi-step problem space explorer and engineering lifecycle showcase.
- **Design System**: Cloudflare Kumo tokens paired with custom dark-mode aesthetics, fluid typography, and responsive micro-layouts.
- **Contact Integration**: Direct email action and EmailJS-powered interactive contact modal.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, CSS Modules, Cloudflare Kumo UI
- **Animations**: Framer Motion, Motion
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ameya2401/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

---

## 📦 Scripts

- `npm run dev`: Runs the development server with Kumo stylesheet synchronization.
- `npm run build`: Compiles the application for production.
- `npm run start`: Starts the Next.js production server.
- `npm run lint`: Runs ESLint checks.
